# letsbeSmart · 국가근로 근로일정 자동 배정

국가근로 출근부에 들어갈 **강의실과 근로내용을 날짜별로 자동 배정**해 주는 웹앱입니다.
설치 없이 브라우저에서 바로 쓸 수 있습니다.

👉 **사용하기: https://아이디.github.io/letsbesmart/**
(배포 후 실제 주소로 바꿔 주세요.)

---

## 이런 규칙을 지켜서 배정합니다

| 규칙 | 설명 |
|---|---|
| 점심시간 제외 | 12~13시는 근로로 등록할 수 없습니다. |
| 주말 근로 불가 | 토·일요일에는 근로를 등록하거나 배정할 수 없습니다. |
| 수업 중 강의실 제외 | 강의실 시간표에 수업이 있는 시간에는 그 강의실을 배정하지 않습니다. |
| 공휴일 근로 불가 | 공휴일에는 등록된 근로가 있어도 배정하지 않습니다. |
| PC 조건 | 'PC 필수' 근로내용은 PC가 있는 강의실에만 배정합니다. |
| 하루 중복 방지 | 하루에 근로가 여러 번이면 강의실과 근로내용이 겹치지 않게 배정합니다. |
| 결과 고정 | 같은 날짜는 언제 다시 열어도 같은 결과가 나옵니다. |

---

## 처음 사용할 때 (5분)

처음 열면 **예시 데이터**가 들어 있습니다.
상단 안내 배너의 **"예시 데이터 지우기"** 를 누르고 아래 순서대로 입력하세요.

### 1. 강의실 · 근로내용 등록
**[강의실 · 근로내용]** 탭
- **강의실**: 이름을 입력하고, PC가 있는 강의실이면 `PC 있음`에 체크한 뒤 추가합니다.
- **근로내용**: 내용을 입력하고, PC가 꼭 필요한 업무면 `PC 필수`에 체크한 뒤 추가합니다.
- 체크박스는 등록한 뒤에도 목록에서 바로 바꿀 수 있습니다.

### 2. 강의실 수업 시간표 입력
**[강의실 시간표]** 탭
1. 위쪽 목록에서 강의실을 고릅니다.
2. 수업이 있는 칸을 누르면 색이 칠해집니다. 누른 채로 끌면 여러 칸을 한 번에 칠할 수 있습니다.
3. 다시 누르면 지워집니다.
4. 강의실마다 반복합니다.

> 칠한 칸 = 수업 있음 = 그 시간에는 배정되지 않음

### 3. 내 근로 시간 등록
**[근로 일정]** 탭에서 유형을 고르고 시간을 등록합니다.

| 유형 | 언제 쓰나요 |
|---|---|
| 학기 중 (요일) | 학기 동안 매주 반복되는 근로 시간 (예: 매주 수요일 9~11시) |
| 방학 중 (요일) | 방학 동안 매주 반복되는 근로 시간 |
| 특정 날짜 | 그날만 따로 정한 근로 시간. 요일 일정보다 우선 적용됩니다. |
| 방학 주간 풀근로 | 날짜 하나를 고르면 그 주 월~금에 09~12시, 13~18시를 한 번에 등록합니다. |

- 오전(9~12시)과 오후(13~18시)는 **따로** 등록해야 합니다. 점심시간을 걸칠 수 없습니다.
- 같은 요일·날짜에 시간이 겹치면 등록되지 않습니다.
- 등록한 일정은 오른쪽 목록에서 **삭제**할 수 있습니다.

### 4. 달력에서 확인
**[달력]** 탭
- 날짜 칸의 `3h` 같은 표시가 그날의 근로 시간입니다.
- 날짜를 누르면 오른쪽(모바일은 아래)에 **시간대별 강의실과 근로내용**이 나옵니다.
- 달력 위에는 이번 달 근로일 수와 총 시간이 나옵니다.
- 달력 아래에는 **강의실별 배정 횟수와 시간**이 나옵니다.

---

## 달력 표시 읽는 법

| 표시 | 의미 |
|---|---|
| 초록색 `3h` | 정상 배정된 근로 시간 |
| 주황색 `3h` | 확인이 필요한 날 (아래 참고) |
| ~~근로 없음~~ (빨간색) | 근로가 등록돼 있지만 공휴일이라 빠진 날 |
| 빨간 날짜 + 이름 | 공휴일 |

**"확인 필요"가 뜨는 경우**
- 그 시간에 비어 있는 강의실이 하나도 없을 때 → 강의실을 더 등록하거나 시간표를 확인하세요.
- 강의실이나 근로내용이 부족해서 같은 날 겹칠 수밖에 없을 때 → 강의실이나 근로내용을 더 등록하세요.
- 강의실이나 근로내용이 하나도 등록되지 않았을 때

## 결과가 마음에 안 들 때

날짜 상세 화면의 **"다른 조합으로 다시 뽑기"** 를 누르면 그날만 새 조합이 나옵니다.
**"처음 조합으로"** 를 누르면 원래 결과로 돌아갑니다.

## 공휴일

**[공휴일]** 탭
- **2026~2027년 관공서 공휴일**이 기본으로 들어 있습니다. 대체공휴일, 2026년 지방선거일(6/3), 노동절(5/1), 제헌절(7/17)이 포함됩니다.
- **휴일 추가**: 개교기념일이나 새로 지정된 임시공휴일은 직접 추가하세요.
- **휴일 해제**: 학교가 쉬지 않는 공휴일은 체크를 끄면 그날도 근로가 배정됩니다.
- 2028년 이후 공휴일은 아직 들어 있지 않으니 직접 추가해야 합니다.

## 데이터 · 설정

**[데이터 · 설정]** 탭

### 학기 / 방학 구분
방학으로 볼 달을 고릅니다. 기본값은 1·2·7·8월입니다.
- 방학인 달에는 '방학 중' 요일 일정이, 나머지 달에는 '학기 중' 요일 일정이 적용됩니다.
- 방학에는 강의실 시간표가 적용되지 않습니다. 계절학기가 있다면 `방학에도 강의실 시간표 적용`을 켜세요.

### 출근부 내보내기 (CSV)
달력에서 보고 있는 달의 근로 내역(날짜, 시간, 강의실, 근로내용)을 CSV로 만듭니다.
**파일로 저장**을 누르면 엑셀에서 바로 열 수 있는 파일이 저장됩니다.

### 백업 · 다른 기기로 옮기기
> ⚠️ 데이터는 **지금 쓰는 브라우저에만** 저장됩니다.
> 다른 컴퓨터나 폰, 다른 브라우저에서는 보이지 않습니다.
> 브라우저 기록이나 사이트 데이터를 지우면 함께 사라집니다.

- **백업 JSON 만들기** → **파일로 저장**으로 백업 파일을 받아 두세요.
- 다른 기기에서는 **JSON 파일 불러오기**로 그 파일을 열면 그대로 옮겨집니다.
- 파일 저장이 안 되는 환경이면 **복사**해서 메모장에 저장해 두고, 불러올 때는 그 내용을 칸에 붙여넣은 뒤 **붙여넣은 내용 불러오기**를 누르세요.
- 기존 윈도우 프로그램의 `MyScheduleData.json`도 그대로 불러올 수 있습니다.

### 전체 초기화
모든 강의실, 근로내용, 일정, 시간표, 직접 추가한 휴일을 지웁니다. 먼저 백업해 두세요.

## 자주 묻는 질문

**Q. 다른 사람이 입력한 데이터가 보이나요?**
아니요. 각자의 브라우저에만 저장되기 때문에 서로 보이지 않습니다.

**Q. 강의실 시간표를 친구들과 같이 쓰고 싶어요.**
한 사람이 강의실과 시간표를 입력하고 **백업 JSON**을 만들어 공유하세요. 받은 사람이 불러온 뒤 자기 근로 시간만 추가하면 됩니다.

**Q. 같은 날짜인데 결과가 바뀌었어요.**
강의실, 근로내용, 시간표 중 하나를 바꾸면 배정 결과도 달라질 수 있습니다. 출근부 제출이 끝난 달은 **CSV로 저장**해 두세요.

**Q. 폰에서도 되나요?**
네. 폰 브라우저에서도 똑같이 쓸 수 있습니다. 다만 데이터는 폰 브라우저에 따로 저장됩니다.

## 배포 (관리자용)

이 저장소는 `index.html` 파일 하나로 동작합니다. 서버나 빌드 과정이 필요 없습니다.

1. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, `/ (root)`로 지정합니다.
2. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.
3. 수정할 때는 `index.html`을 다시 업로드하면 같은 주소에 반영됩니다.

> 개인 일정이 담긴 백업 JSON이나 `MyScheduleData.json`은 저장소에 올리지 마세요. 공개 저장소는 누구나 볼 수 있습니다.
